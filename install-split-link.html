X 通知头像 · 原生分屏联动

左边看通知，点头像让右边打开原生主页。帖子、滚动和回复均由 X 自己处理。

1. 安装脚本

  1. 在 Chrome 或 Edge 中安装并启用 Tampermonkey（油猴）。
  2. 点击下方“复制脚本”，再点油猴图标 → 添加新脚本。
  3. 删除编辑器里的默认内容，粘贴本脚本，按 Ctrl+S 保存。
  4. 刷新已经打开的两个 X 页面。不要再启用之前的实验版书签。

2. 设置分屏

  1. 手动开启浏览器原生分屏；左侧打开 X 通知页，右侧打开任意 X 主页。
  2. 右侧页面左下角展开“X 分屏联动”，点“设为右侧接收页”。
  3. 点击左侧通知头像，右侧会跳转到对应用户主页。之后继续点击其他头像即可复用右侧。

两个页面需要在同一个浏览器配置中，并启用同一份脚本。脚本不会自动创建分屏，也不会自动发布回复。换到新接收页时重新指定即可。

使用说明

  • 右侧有可检测到的未发送文字或附件时，会暂缓跳转，由你确认或取消。
  • 暂停左侧头像联动后，头像恢复 X 默认行为。Ctrl/Shift/中键等操作保持原样。
  • 每个浏览器配置只指定一个接收页；Chrome 与 Edge 之间不会互相联动。
  • 如果页面左下角没有面板，先检查油猴内本脚本是否启用，以及浏览器是否提示需要允许用户脚本运行。

已通过 Chrome、Edge 隔离页面的通信逻辑测试（模拟油猴接口）；实际油猴安装与浏览器原生分屏组合仍需你安装后验证。
